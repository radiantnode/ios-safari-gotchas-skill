theme-color probes

Each page is its own path, because Safari remembers the colours it latched per path (SKILL.md §3). Colours: body magenta #ff00ff, theme-color green #00ff00, element red #ff0000, stripes white and grey. Each page scrolls itself to y=1500 thirty seconds after load.

Result, 2026-09-29 (iPhone 18 Pro, iOS 27.0 simulator, Compact tab bar, "Allow Website Tinting" on): theme-color had no visible effect. No green pixel appeared in any of the 14 screenshots. The status bar read body's magenta, or the red stage's colour on flat-red. Each page with the tag was pixel-identical to its twin without it in the strip and the toolbar. flat-red flat-filled in the stage's red. flat-clear (transparent, nothing opaque inside) did not flat-fill.
